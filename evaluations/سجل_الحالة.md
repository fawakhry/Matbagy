# سجل الحالة العامة — برنامج تقييمات مطبعجي

**آخر تحديث توثيقي:** 2026-09-24، ضمن طلب المالك تسجيل خطة العمل بين الشاتات على GitHub. هذا السجل معلومات عامة غير شخصية. عند استكمال أي شات اقرأ الملفات الحية أولًا ثم تحقّق من GitHub، ولا تعتبر تاريخ هذا السجل إثباتًا لحالة خادم Cloudflare أو وجود ملف عميل خاص.

## ثبت بالقراءة/الكتابة
- مشروع TrendOS منفصل عن برنامج التقييمات؛ لا تعديل على أي ملف TrendOS أو قاعدة `trendos-main`.
- فرع `main` في `fawakhry/Matbagy` متاح للكتابة لكنه **PUBLIC**؛ هذا المسار `evaluations/` توثيق انتقالي عام، لا مخزن عملاء.
- خطة المالك: رفع محادثات هنا وتحليلها يدويًا؛ في أي شات جديد يبدأ بالأمر «جت هب برنامج التقييمات» لقراءة «اقرأني أولًا»؛ «حدّث» يستدعي آخر بصمة محفوظة فعليًا؛ «شوف المشكلة» يجمع البصمة مع أدلة الواقعة الجديدة.
- V4 الحالي وكتَيّبه نُفذا محليًا في محادثة سابقة؛ لا تُعامل رابط حزمة المحادثة كسجل كود في GitHub؛ لا توجد خدمة تقييمات منشورة مثبتة هنا.

## غير متحقق/غير منفذ
- إنشاء مستودع GitHub خاص ببرنامج التقييمات ورفع ملفاته إليه.
- حفظ أو تحديث أي بصمة عميل حقيقية عبر GitHub الخاص، أو الوصول إلى ملفاتها من شات جديد.
- إنشاء Worker/D1/R2 مستقلين أو ربط OpenAI API/WhatsApp/TrendOS.
- الإرسال التلقائي أو أوامر تغيّر شغل المطبعة.

## نقطة الاستكمال العملية
أولًا: التحقق من **وجود مستودع خاص** للتقييمات وإنشائه بموافقة المستخدم ومن خلال إمكانات متاحة؛ عدم استعمال المستودع العام لحفظ ملفات عملاء. ثانيًا: نقل قواعد التشغيل وكود V4 بعد فحصه؛ إنشاء تخزين البصمات الخاص وتجربة عميل وهمي واستدعائه من شات جديد؛ ثم بيانات حقيقية بتصريح ومراجعة؛ ثم مراحل الواجهة وCloudflare وAPI. لا تدّع استكمال أي بند بلا دليل رابط/إصدار/قراءة تحقق.
